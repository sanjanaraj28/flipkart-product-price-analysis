# 🛒 Flipkart Product Price Analysis

## 📌 Project Overview

This project analyzes Flipkart product data to understand product pricing, brands, categories, ratings, discounts, and customer reviews.

The project focuses on **data cleaning, exploratory data analysis (EDA), and visualization** to identify useful patterns and insights from the dataset.

---

## 🎯 Objectives

* Analyze product prices across different categories.
* Identify popular brands and products.
* Study the relationship between price, ratings, and reviews.
* Analyze discounts offered on products.
* Compare product categories based on pricing and customer ratings.
* Create visualizations to communicate important findings.

---

## 📊 Dataset

The dataset contains **2,525 products** and **11 columns**.

### Main Information

* **Total Products:** 2,525
* **Unique Brands:** 222
* **Categories:** 6
* **Columns:** 11

The dataset contains information related to product names, brands, categories, prices, discounts, ratings, and review counts.
